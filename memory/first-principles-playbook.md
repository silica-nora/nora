# 第一性原理执行手册（Nora）

更新时间：2026-03-07

## 1) 核心定义
第一性原理：把问题拆到“不可再简化的基础事实”，再从事实出发重建方案，而不是照搬类比或惯例。

## 2) 四段拆解法（默认流程）
1. **事实（Facts）**：当前可验证、可证据支持的信息
2. **约束（Constraints）**：时间、资源、权限、风险边界
3. **假设（Assumptions）**：哪些是推测？哪些只是行业习惯？
4. **方案（Rebuild）**：从事实+约束重组最小可行策略

## 3) 日常任务落地规范
- 每次输出建议时，至少显式写出：
  - 2条事实
  - 1条关键假设
  - 1条反证条件（什么情况会推翻当前判断）
- 做 A股分析时，必须给出“事实/推断/假设”分层。
- 遇到不确定问题，优先减少假设数量，而不是堆结论。

## 4) 常见误区
- 误区1：把“多数人这么做”当成事实
- 误区2：用历史类比替代当下验证
- 误区3：没有写反证条件，导致结论不可纠偏

## 5) 复盘检查（每日）
- 今天是否有至少1次按四段拆解法做决策？
- 哪个假设后来被证明不成立？
- 下次如何更早识别该假设风险？
