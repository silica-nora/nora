# Heartbeat >7天待跟进 快速判定清单

更新时间：2026-03-20 06:48 CST

## 目标
在不漏项前提下，减少把“历史过程记录”误判为“当前待办”。

## 1-2-3 判定顺序
1. **先看当前态**
   - `SESSION-STATE.md` 的 Current Task / Pending Actions 是否有未完成项（`[ ]`）。
2. **再看最近态**
   - 仅扫描最近 2 天 `memory/YYYY-MM-DD.md` 是否出现“待跟进/未完成/TODO”且没有“已完成/收口”结论。
3. **最后看历史态（>7天）**
   - 只把“仍未收口”的事项计入待办；若后续日期已有“已完成/已定稿/已收口”记录，则视为已闭环，不再重复推进。

## 触发升级条件
- 任一层出现“明确未闭环事项”→ 本轮优先推进并汇报。
- 三层均无未闭环事项 → 进入自我强化任务（至少1项）并落盘。
