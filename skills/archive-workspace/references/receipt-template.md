# 归档回执模板（精简默认）

## A. 无变更（默认最短）
```text
归档完成 ✅ 无变更（无需推送）
```

## B. 有变更（按 tk 规范）
```text
归档完成 ✅

改动摘要：<一句话，先说结果/价值>

变更概览
• 新增：<无 或 N 个文件：file1；file2>
• 修改：<无 或 N 个文件：file1；file2>
• 删除：<无 或 N 个文件：file1；file2>

提交信息
• commit：<short_sha>
• push：<成功|失败|待推送/上传|待执行>
```

## C. 仅异常时补充
- failure_code: <code>
- 下一步建议: <一句话>
